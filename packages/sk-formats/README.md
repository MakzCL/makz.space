# @sk/formats: SK Suite file-format SDK

Content-based detection of file formats and versions, the importer/exporter registry, and import reports, shared by TROTAN, CADRA, NUCLEUS and Kortana. It has no runtime dependencies.

```
npm test                                          # 38 detection, routing and evidence tests
node --experimental-strip-types scripts/matrix.ts # regenerate docs/FILE_FORMAT_SUPPORT_MATRIX.md
```

Docs: `docs/SK_FILE_INTEROPERABILITY.md` (architecture and research), `docs/FILE_FORMAT_SUPPORT_MATRIX.md`, `docs/IMPORT_EXPORT_TESTS.md`, `docs/DEPENDENCIES_AND_LICENSES.md`.
