# SK FACTORY — zwiastun · scenorys

**Format:** 1920×1080, 60 kl./s, MP4 (H.264 + AAC) · **Długość:** 90 s · **Język:** polski
**Lektor:** męski, spokojny, pewny siebie (pl-PL-MarekNeural) · **Muzyka:** autorska, minimalistyczna elektronika 116 BPM, d-moll, narastająca energia, kulminacja na „SK Factory”
**Styl:** taki sam jak zwiastun KORTANA, w kolorach SK (czerwień + granat), nagrania w ramce telefonu.
**Materiał:** prawdziwe nagrania aplikacji SK Factory (zapis klatka po klatce z przeglądarki) na danych demonstracyjnych. Każda akcja jest wykonana naprawdę: rozpoczęcie zmiany, start zlecenia, przekazanie przytrzymaniem, wysłanie wiadomości, zgłoszenie problemu, zatwierdzenie wniosku.

## Pokazane funkcje

| W zwiastunie | Gdzie w aplikacji |
|---|---|
| Rozpoczęcie zmiany jednym dotknięciem | Start → „Rozpocznij pracę” |
| Ekran startowy: kto jest na hali, co trwa | Start (Na hali, Hala na żywo, Tablica ogłoszeń) |
| Zlecenia według priorytetu, trasa przez stanowiska | Zlecenia → karta zlecenia |
| Przekazanie dalej przytrzymaniem | „Przytrzymaj po skończeniu → stanowisko” |
| Czat, rozmowy głosowe i wideo | Czat |
| Kalendarz spotkań | Czat → Kalendarz |
| Zgłoszenie problemu | karta zlecenia → „Zgłoś problem” |
| Wnioski urlopowe | Wnioski → „Zatwierdź” |
| Godziny pracy i postęp zleceń | Analizy |
| Zespół na żywo; telefon, tablet i komputer | Zespół; wersja na komputer |

Pominięte celowo: skanowanie kodów (wyłączone w aplikacji).
